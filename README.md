# AM's Homework Helper

原生 macOS 截止时间管理器，支持日历、任务编辑、本机提醒和任务备份。**AM's Homework Helper** 意为 AceMetric 的作业助手，在 [原作者的 DDL-Manager](https://github.com/123456p-df/DDL-Manager) 基础上增加 GitHub 课程作业管理和应用内更新功能。

适用于 **macOS 13+、Apple 芯片**。

## 功能

- 统一管理作业 DDL，使用日历、菜单栏及系统提醒。新任务默认提前 7 天、3 天、1 天、1 小时和到期提醒。
- 常驻侧栏统一“总览、日历、任务、待审核作业、课程”；浅色和深色自动跟随 macOS，使用统一的蓝色强调与原生弹窗、菜单。
- 从老师仓库当前默认分支的 Markdown、纯文本等文档发现作业；启动时、每 6 小时及手动检查。
- 提取作业名称、内容概括、提交要求和完整相关原文；完整明确日期的新作业可自动加入并撤销，含糊结果留待审核，老师更新原文时提供建议。
- 识别中文完整日期、星期附注与时区；日期缺少时间时要求补全。相对日期按截止语句的上游提交时间给出建议，确认后才导入。
- 区分作业、课上任务和考试。考试题目归属同一次考试，只在课程页标注；支持类型筛选与人工修正。
- 关联本地课程仓库，合并老师上游、处理冲突、逐项选择文件提交。
- 应用内检查新版本、查看更新说明、确认下载与重启；未保存内容和正在执行的作业操作受到退出保护。
- **作业只推送到经核验属于当前登录用户的个人 fork，绝不推送到老师仓库，也不强推。**

## 安装与使用

从 [GitHub Releases](https://github.com/AceMetric/AM-Homework-Helper/releases/latest) 下载 **1.4.1** 的 `AM-Homework-Helper-1.4.1-macOS-arm64.zip`，安装说明与校验文件作为独立附件提供。当前构建使用临时签名，**未经 Apple 公证**。

解压后将 `AM's Homework Helper.app` 放入“应用程序”。首次打开若被系统阻止，可在“系统设置 → 隐私与安全性”按系统提示选择“仍要打开”。更新前退出正在运行的旧测试版。

从 DDL-Manager 或 AM's Homework Helper 1.1 / 1.1.1 测试版升级时，需要手动安装最新版，替换旧应用。旧测试版的更新地址不再使用；已有任务、课程绑定和登录信息继续沿用。

### 软件更新

从应用菜单选择“检查更新…”，或在“设置 → 软件更新”管理自动检查。1.1.2 起使用公开 HTTPS 更新源，无需 GitHub 登录；默认每天检查，由你确认下载和安装。更新会等待课程操作结束，并提示处理未保存内容。断网或服务故障可稍后重试，不影响本机任务使用。[完整更新说明](docs/UPDATES.md)。

### 日历与提醒

打开应用后进入“今日与近期安排”，按逾期、今天和未来七天查看未完成任务。“日历”支持连续月份、月份跳转、定位今天及选中日期的任务；窄窗口会把当天任务移到日历下方。“任务”中可筛选已完成、归档和最近删除。

点击“新建任务”填写任务、截止时间和提醒；也可粘贴公告或识别截图。仅填写一个作业 DDL，完整日期及有提交依据的相对日期建议自动预填，核对后直接保存。缺少时间或日期矛盾时仍需补全。识别出的新作业以概括和提交要求预填备注，可修改或清空；普通新建任务备注仍为空。已有备注和用户修改不会被来源更新覆盖，老师原文独立展示。旧任务的截止时间、备注与提醒保留。新建和普通任务编辑使用弹窗；课程页及待审核页的作业均直接在列表旁编辑、确认，不弹出审核窗口。保存后从审核列表移除，通过“任务”或“已加入任务”继续修改。备注默认隐藏，选中任务后在详情栏显示。长内容可滚动，日期选择器按需展开；弹窗中 Return 保存、Escape 取消，多行备注中 Return 正常换行，⌘Return 保存。外观自动跟随电脑，不需要选择配色。

通知权限在侧栏“设置 → 提醒设置”中管理，可用“提醒测试”检查。关闭主窗口后应用继续在菜单栏运行；退出应用、关机或休眠期间无法定时扫描。已安排的本机通知由系统管理；是否按时显示仍受权限、专注模式和系统状态影响，不能保证送达。

“文件 → 恢复任务…”可预览最近10次修改及最近7天的每日备份，确认后恢复并可撤销。损坏任务文件不会被空任务覆盖；需要恢复后才能继续保存。“设置 → 数据与反馈”可预览并导出仅含阶段、结果类别和耗时的诊断，不会自动上传。

原版用户可先导出任务备份，再在本版“任务 → 导入任务备份…”导入。备份可能包含任务备注和来源，分享前请检查个人信息。

### GitHub 课程作业

1. 首次打开跟随四步引导，点击“浏览器登录”，复制验证码并打开 GitHub。网页授权对象是内置的 **GitHub CLI 官方工具**；无需安装工具、生成 SSH 密钥或申请学校批准本项目应用。学校 SSO 和已有课程访问权限仍需本人完成。
2. 一次勾选多门个人课程 fork，自动核验私有老师上游权限。选一个课程总文件夹，软件仅检查该目录及下两层，按 Git 身份匹配；有多个匹配时由你选择。未找到的课程可批量下载，不覆盖已有目录。
3. 在主侧栏选择课程，点击“检查新作业”（“所有课程”可以一次检查）。所有课程的新作业与更新建议集中在“待审核作业”，可按课程、关键词及新作业／更新建议筛选。
4. 选中即可在右侧核对名称、内容和作业 DDL，点“保存并下一项”（⌘Return）。可“全选当前结果”或列表聚焦时按⌘A；搜索或筛选变化会取消隐藏条目的选择。批量预览逐项显示可保存日期与需补全原因，确认后只加入通过校验的条目。校验通过的模型结果和有提交依据的相对日期也可人工批量确认；不完整条目继续待审核。保存失败会在表单顶部说明原因并保留填写。“本周日”等显示截止语句的上游提交依据，可靠建议自动填入截止时间，无需点“采用建议日期”；没有可靠依据时手填完整日期。缺少时间不默认 23:59。切换条目、退出或更新前保护未保存输入；原文更新不覆盖用户修改。
5. “同步课程文件”会获取并合并老师更新，再安全推送到自己的 fork；有本地修改或分歧时会暂停。冲突显示继续入口，失败后在该课程查看原因。
6. “提交作业”显示个人 fork 与目标分支；文件默认不勾选，可先查看变更，再逐项选择并填写提交说明。敏感文件不可提交，推送前仍会检查完整提交范围。推送失败时保留本地提交，修复原因后使用“重试推送”。

侧栏“开始使用”可重看检查、审核、同步、提交的简短说明，或重新运行配置引导；提示不会自动同步或提交。

“更多”提供课程关联、自动检查、仓库与操作详情、移除等操作。当前操作显示阶段并锁定写操作，浏览其他页面或课程不会改变正在执行的目标。侧栏账户入口可取消尚未完成的设备登录；Git 写操作不提供中途取消。

默认开启安全自动加入：只处理未来、完整绝对日期的新作业，要求来源和分类明确且无冲突；历史过期材料、相对日期、缺失时间及模型新发现仍待审核。“任务 → 撤销本次自动加入”只移除本轮未编辑的任务，撤销后的同版原文留待人工审核，⌘Z 可撤销其他任务操作。在设置中可以关闭自动加入。“任务”菜单还可批量完成当前筛选的任务。

审核通过的作业立即从待审核页和课程内容的作业列表移除，可在“任务”或课程的“已加入任务”继续查看、编辑。老师更新原文后，才重新显示为更新建议。总览、任务和日历默认不显示备注；选中任务后在详情栏查看，Escape 可关闭详情。

### 可选增强识别

默认免费规则，无需模型。设置的高级识别中保留 **Ollama 本地模型**和 **OpenAI 兼容云 API**；模型增强初始关闭，不自动下载模型，不在本地失败后转发云端。云端须勾选允许发送老师文档的课程并确认范围，密钥只存钥匙串且与服务地址绑定；每天最多 20 次请求（失败计入），达到上限继续规则识别。次数上限不等于固定费用。

课程直接展开在主侧栏；切换课程保留各自搜索与筛选。检查只读取老师内容；同步会合并课程文件并更新个人 fork，提交则先选择文件。

推荐用共用 Skill 处理复杂材料：点击“助手识别” → 首次选择课程 → 复制指令给助手 → 结果自动接回待审核。以后记住课程，无需再选择保存目录或手动导入。只准备新增或变化的老师材料，接回前核验最新版本和原文。可在“更多 → 识别批次与进度”的应用内列表查看状态、复制指令或重试；部分成功后可只重新准备未成功材料，30天前已完成的材料包自动清理，进度仍保留；旧格式保留手动导入。Skill 不直接修改任务，也不执行课程 Git 操作或自动创建定时任务。[识别配置与隐私说明](docs/RECOGNITION.md)。

自动接回需要使用能读写本机材料目录的助手（例如本机 Codex）。只有网页对话、无法写入本机文件时，仍可使用兼容的手动导入；应用不会替你发送材料或发起付费分析。

“课程 → 课程内容”可按作业、课上任务、考试或待确认类型筛选，并查看原文。考试与课上任务不会进入待审核作业、日历或提醒。识别有误时选择内容后点“更改类型…”，修正保存在本机并用于后续检查；已有任务不会被自动删除。明确的作业即使未说明截止时间，也会进入审核；教材示例、目录链接和作业中的普通日期叙述不会作为截止要求。

快捷键：⌘1 总览、⌘2 日历、⌘3 任务、⌘4 待审核作业、⌘G 课程、⌘N 新建、⌘F 搜索当前页面。

默认内置 GitHub CLI 2.101.0 官方浏览器登录，申请 `repo`、`read:org`、`gist`，范围比所选课程更宽；应用仅处理所选课程。CLI 属于 GitHub 特许应用，不依赖学校批准本项目 OAuth；个人登录、SSO 与已有课程权限仍是前提。[登录、迁移和维护说明](docs/GITHUB_APP_SETUP.md)。

## 数据与安全

官方 CLI、旧 OAuth 与旧 GitHub App 的本应用令牌分开保存；新登录不会自动撤销旧 App 安装，应在 GitHub 设置中单独撤销。GitHub 访问令牌和刷新令牌只保存在本机钥匙串，不进入仓库、日志或任务备份。本项目不附带私钥或自建认证密钥，不更改全局 Git 配置。内置官方工具保留原签名与许可证；写入保护禁止明文配置回退。退出本应用不撤销其他 CLI 工具的共享授权。

更名后继续沿用旧测试版的内部标识与数据位置，已有任务、课程关联及登录信息可继续使用：

- Bundle ID：`io.github.acemetric.sshomeworkmanager`。
- 数据目录：`~/Library/Application Support/SS Homework Manager/`。

该目录与原版 DDL Manager 独立；原版任务仍通过备份导入。详细推送校验、凭据处理和提交限制见 [安全说明](docs/SECURITY.md)。

## 识别范围与验证状态

默认使用本地规则、可选模型增强，扫描文本文档，支持 Markdown、纯文本、RST、AsciiDoc、Org 和 TeX；不解析 PDF / Office 附件。附件作业可从正文中的说明发现，但不会自动读取附件内容。单文件最多 1 MB，单次文档总量最多 30 MB。

构建、模拟 GitHub API、临时 Git 仓库及 AppKit 回归已验证。真实账户设备登录、私有课堂仓库操作和通知送达仍需在实际使用环境中核对。完整记录见 [验证状态](docs/VERIFICATION.md)。

## 开发与贡献

需要 macOS Command Line Tools 和系统 Python 3；首次构建会下载并校验固定版本的 Sparkle，同时编译 SwiftUI 桥接模块：

```sh
zsh build.sh
zsh test.sh
zsh verify-homework.sh
```

构建产物为 `build/AM's Homework Helper.app`。模块说明、完整验证命令、打包流程和贡献注意事项见 [开发与贡献](docs/CONTRIBUTING.md)。
